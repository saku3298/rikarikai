【GitHubへの公開手順】
1. GitHubで「rikarikai」というPublicリポジトリを新規作成します。
2. このZIPを展開します。
3. rikarikaiフォルダの「中身」をすべてリポジトリ直下へアップロードします。
   ※ rikarikaiフォルダそのものを入れないでください。
   ※ index.htmlがリポジトリの一番上に見える状態が正解です。
4. 「Commit changes」を押します。
5. 「Settings」→「Pages」を開きます。
6. Sourceで「Deploy from a branch」を選択します。
7. Branchを「main」、フォルダを「/ (root)」にして「Save」を押します。

公開URL（GitHubユーザー名がsaku3298の場合）
https://saku3298.github.io/rikarikai/

【閲覧方法】
PC：左右ボタン、左右キー、マウスホイールでページ移動
スマートフォン縦向き：1ページ表示・横スワイプ
スマートフォン横向き：右に若いページを置く2ページ見開き
